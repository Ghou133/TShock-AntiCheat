# 配置、执行模式与运维边界

[首页](../README.md) · [源码状态](STATUS.md) · [构建](BUILDING.md)

配置文件为 TShock 保存目录的 `anticheat.json`。加载入口是 `M2Configuration.Load`。当前在插件初始化时读取，没有文档化的热重载命令；更改后应在隔离副本重启验证。

## 配置字段

| 字段 | 默认值 | 实际含义 |
| --- | --- | --- |
| `ExecutionScope` | `ObserveOnly` | 全局执行范围；不能单独增加规则生产资格 |
| `M18CandidateMode` | `Auto` | 决定对应候选模块的观察与控制模式 |
| `M18RecordObservations` | `true` | 允许有限观察；运行资格及模块状态仍需满足 |
| `M18EnableBlocks` | `true` | 候选阻断请求开关；默认观察范围下不因此启用候选控制 |
| `M18EnableServiceKick` | `null` | 自动模式且处于 TestLab 时可取 true；插件仍限制相关生命规则只在 TestLab 踢出 |
| `M18EnablePermanentSanctions` | `false` | 当前 NPC/掉落物候选在插件接线处仍强制关闭，设 true 也不能获得永封能力 |
| `ExperimentalLiquidScheduler` | `false` | 实验液体调度限制；不控制所有液体、泵或区域保护 |

文件缺失、无效 JSON、非法枚举或超过 8192 字节时回退保守配置，并提供原因。不要依靠手写不完整 JSON 来启用实验。

## 三种执行范围

**ObserveOnly：** 不产生新的作弊账号永久处罚；版本未匹配时也会降到此范围。仍可能阻断畸形输入、执行独立预算和维护模式限制。它不是“卸载所有 Hook”或完全被动旁路。

**TestLab：** 只有绑定回环地址、设置绝对路径 `ANTICHEAT_LAB_ROOT`、根目录含普通文件 `.anticheat-lab`、保存目录在根目录内且路径没有重解析点等条件满足后才保留资格。失败时退出 TestLab；候选控制同时关闭。标记和路径检查用于避免误用环境，不是对抗本机管理员的安全沙箱。

**Production：** 仍依赖源码中的规则白名单、版本、上下文与精确运行指纹。当前没有完整生产发行资格。不能通过改一个 JSON 字段把所有检测启用。

## 候选模式

| 模式 | 观察 | 候选控制 |
| --- | --- | --- |
| `Auto` | 在三个有效范围内按模块开关记录 | 仅 TestLab 可启用 |
| `Disabled` | 对应候选观察关闭 | 关闭；不是所有历史安全控制的总开关 |
| `TestLabCandidate` | 必须匹配 TestLab | 还要满足隔离与模块开关 |
| `ProductionCandidate` | 必须匹配 Production | 仍要求同一隔离回环边界；不是公网候选发布模式 |

候选开关不覆盖模块固有禁用：普通 NPC 批量打击序列的永久处罚关闭；掉落物清除候选的阻断、踢出、永封关闭；生命候选服务踢出只在 TestLab。不要把模式名字与实际行为混用。

## 运行文件

| 保存目录内路径 | 用途 | 注意事项 |
| --- | --- | --- |
| `anticheat-runtime-evidence.json` | 加载身份、范围、规则和部分接线证据 | 有运行路径信息，对外发布前脱敏 |
| `m18-observations.json` | 有界候选观察 | 不是处罚账本，不保证记录每个事件 |
| `anticheat/enforcement/` | 不可丢弃的待执行处罚、已执行证据、运行安全标记 | 不得手工清空后声称完成恢复 |

启动日志中的 `runtimeVerified`、`scope` 和 `configuration` 原因必须检查；`ANTICHEAT_M1_INITIALIZED` 只是历史名称的初始化标记，不保证所有模块健康或生产可用。

## 故障与恢复

观察日志异常会退避或降级，不得产生处罚。处罚存储、恢复、容量等关键问题可能进入维护模式并停止接纳或写入，不能保证游戏完全不受影响。

当前异常退出后的人工确认恢复尚缺少完整公开操作工具。应保留事故现场、数据库与日志，核对可能未持久化的处罚窗口，再使用经审查的恢复流程；不要把删除文件作为常规修复。R4-01 要补齐运维状态、恢复与解封的一致性流程。

权限例外及 SSC 相关条件取决于具体规则，不能把任意管理员组或单个 Buff 视为全局免检。权限语义变化应与规则测试一起审查；本页不新增权限节点或宣称存在未实现的配置项。
